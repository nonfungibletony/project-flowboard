## Problem

Corepack-shimmed pnpm (v11.1.2) crashes with `ERR_VM_DYNAMIC_IMPORT_CALLBACK_MISSING` on Node.js 20.19.2.

Stack trace:
```
node:internal/modules/esm/utils:266
  throw new ERR_VM_DYNAMIC_IMPORT_CALLBACK_MISSING();
```

## Changes

- **`deploy.sh`**: Adds `corepack disable` before any `pnpm` calls.
- **`check_pnpm()`**: Hardened to:
  - Suppress stderr when probing `pnpm -v` (handles the crash gracefully).
  - Detect missing / too-old / broken pnpm.
  - Reinstall via `npm install -g pnpm@9` when needed.

## Test

Reproduced on target LXC with Node 20.19.2 + corepack pnpm 11.1.2.
